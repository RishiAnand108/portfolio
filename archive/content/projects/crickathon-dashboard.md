## Overview

Crickathon Dashboard is a dashboard platform with a Python backend. The work covers the core
pieces of a production-style web service: a set of backend APIs, user authentication, a
relational database, and a containerised deployment.

## Stack at a glance

- **FastAPI** for the backend API layer
- **PostgreSQL** as the primary database
- **Firebase** as part of the platform's managed services
- **Next.js** for the dashboard front end
- **Docker** for packaging and deployment
